⚡ Dicas de Performance

🎬 Vídeos 360°

  • Use H.265/HEVC codec
  • Resolução 4K máximo
  • Bitrate 20-40 Mbps
  • Formato equirectangular

🎨 Texturas

  • Máximo 2048x2048 mobile
  • Use compressão (JPEG, WebP)
  • Evite mipmaps em videos
  • RGB ao invés de RGBA

🎵 Áudio

  • Máximo 8 fontes simultâneas
  • Use spatial audio apenas quando necessário
  • Compressão AAC ou Opus
  • Bitrate 128-192 kbps

💾 Memória

  • Limite 256MB de texturas
  • Dispose recursos não usados
  • Monitor memory usage
  • Object pooling para palavras
