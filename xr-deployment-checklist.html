✅ Checklist de Deploy Android XR

Siga todos os passos para garantir sucesso

0%

🔧 Pré-Deploy

⬜

Testar no Desktop CRÍTICO

Abra cada arquivo -xr.html no navegador e teste funcionalidade básica

# Arquivos para testar: - respiracao-xr.html - paisagem-xr.html - palavras-xr.html - android-xr-native.html
⬜

Verificar Console Errors CRÍTICO

Abra DevTools (F12) e verifique se não há erros JavaScript no console

⬜

Otimizar Vídeos 360° IMPORTANTE

Comprima vídeos para 4K máximo, H.265, 20-40 Mbps

# Exemplo FFmpeg: ffmpeg -i input.mp4 -c:v libx265 -b:v 30M \ -vf scale=3840:1920 -c:a aac -b:a 192k output.mp4
⬜

Otimizar Áudio OPCIONAL

Comprima arquivos de áudio para 128-192 kbps

# Converter para AAC: ffmpeg -i input.mp3 -c:a aac -b:a 192k output.aac

🌐 Configuração de Hosting

⬜

Escolher Plataforma de Hosting CRÍTICO

WebXR requer HTTPS. Opções recomendadas:

  • GitHub Pages - Grátis, fácil setup
  • Netlify - Grátis, deploy automático
  • Vercel - Grátis, muito rápido
  • Firebase Hosting - Grátis, Google infra
⬜

Configurar HTTPS CRÍTICO

WebXR não funciona sem HTTPS. Todas as plataformas acima já incluem.

⬜

Upload de Arquivos CRÍTICO

Fazer upload de todos os arquivos necessários:

Arquivos essenciais: - index.html - *.html (todos os XR) - xr-components.js - xr-optimization-guide.js - app/manifest.json - videos/*.mp4 - *.mp3 (áudio) - cenarios/*.png
⬜

Configurar CORS IMPORTANTE

Permitir CORS para vídeos e áudio se usar CDN externo

# Exemplo Netlify (_headers file): /* Access-Control-Allow-Origin: * Cross-Origin-Resource-Policy: cross-origin

📱 Configuração PWA

⬜

Verificar Manifest.json CRÍTICO

Confirme que app/manifest.json está atualizado com xr_capabilities

⬜

Configurar Service Worker OPCIONAL

Para funcionar offline (app/service-worker.js já existe)

⬜

Testar como PWA OPCIONAL

Chrome DevTools > Application > Manifest > Verificar instalabilidade

🥽 Teste em Dispositivos

⬜

Teste em Smartphone Android CRÍTICO

Acesse URL via Chrome Android e teste modo inline (sem VR)

⬜

Teste com Cardboard/Simple VR IMPORTANTE

Use modo VR básico para validar estereoscopia

⬜

Teste em Meta Quest IMPORTANTE

Abra no browser nativo do Quest e entre em VR

⬜

Teste Hand Tracking OPCIONAL

Em Quest, ative hand tracking e teste interações

Quest: Settings > Hands and Controllers > Hand Tracking: ON
⬜

Teste Performance IMPORTANTE

Verifique FPS usando stats em paisagem-xr.html

  • Target: 72+ FPS
  • Mínimo aceitável: 60 FPS
  • Se menor, reduza qualidade ou vídeo

✔️ Validação Final

Features Detection Working CRÍTICO

Abra android-xr-native.html e veja quais features estão disponíveis

⬜

Spatial Audio Funcionando IMPORTANTE

Teste respiracao-xr.html e confirme áudio 3D posicional

⬜

Gaze Interaction Working IMPORTANTE

Olhe para esferas em paisagem-xr.html e veja labels aparecerem

⬜

Session Tracking Working OPCIONAL

Verifique timer de sessão e eventos de início/fim
